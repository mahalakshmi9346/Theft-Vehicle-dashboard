# Excel Dashboard Project

## 📊 Project Overview

This project is an interactive Excel Dashboard created to analyze and visualize data in an easy-to-understand format.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis

## 📈 Dashboard Features

- Interactive dashboard
- Data visualization using charts
- Pivot table analysis
- Slicers for filtering data
- Key performance insights

## 🔍 Key Insights

The dashboard helps users understand important patterns and trends in the dataset through interactive charts and visualizations.
